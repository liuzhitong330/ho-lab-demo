# Ho Lab research demo

An interactive, paper-grounded evidence map prepared by Cathy Liu for the UCSF Ho Lab Junior Specialist application (JPF05959).

The demo organizes published aggregate results from Maggio et al. (2020), focusing on how PP2A inhibition and PD-1 blockade interact in orthotopic GL261 glioblastoma models. It is a structured secondary analysis, not a raw-data reanalysis.

## Sources

- [Maggio et al. (2020)](https://pmc.ncbi.nlm.nih.gov/articles/PMC7467059/)
